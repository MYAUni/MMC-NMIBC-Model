This repository contains MATLAB scripts for the analyses and figures presented in the manuscript:
'Cancer Stem Cells and Antitumor Immunity in MMC-Treated Bladder Cancer: A Mechanistic Model'

The code for generating the supplementary figures is included in the corresponding main-figure scripts. The repository also includes scripts for assembling Supplementary Data 2 and Supplementary Data 3 from the outputs of the corresponding manuscript analysis sections.

Where analysis and figure generation are provided as separate scripts, run the analysis script first to generate the required results. Existing saved results can subsequently be used by the corresponding figures script.
